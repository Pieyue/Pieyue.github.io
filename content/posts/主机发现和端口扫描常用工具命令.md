## Nmap常用参数

注：-sS(半握手扫描)、-O、-sU、-PR等扫描必须用sudo

```bash
sudo nmap -sn 192.168.200.0/24                      # 扫描整个C段
sudo nmap --min-rate 10000 -p- 192.168.200.1        # 快速全端口开放探测
sudo nmap -sU --min-rate 10000 -p- 192.168.200.1    # 快速全端口开放探测(UDP)
sudo nmap -sU --top-ports 20 192.168.200.1          # 对常用的20个UDP端口进行扫描
sudo nmap -sT -sV -O -p80,777,52497 172.16.120.131  # 同时对目标端口进行TCP扫描+版本探测+目标操作系统检测
sudo nmap --script=vuln -p80,111 172.16.200.131     # 对目标端口进行漏洞扫描
```

可以使用-oA参数保存扫描结果, nmap会将扫描结果保存为gnmap, nmap, xml三种格式, 使用以下命令可以提取扫描结果中所有开放端口, 并赋给变量$ports

```shell
ports=$(grep open ports.nmap | awk -F'/' '{print $1}' | paste -sd ',')
```

## 无Nmap环境的主机发现(ping扫描)

| 命令/参数 | 解释 |
| --- | --- |
| -c | 发送数据表数量 |
| -W | 超时时间 |
| {1..254} | 从1到254的数字序列 |
| grep from | 存活主机的结果中会存在from这个单词，据此过滤即可只输出存在主机 |

```bash
for i in {1..254}; do ping -c 1 -W 1 172.16.200.$i | grep from; done
```

## 无Nmap环境的端口扫描

### netcat实现端口扫描

使用netcat实现端口扫描要使用旧版本，在kali中为nc.traditional  

| 命令/参数 | 解释 |
| --- | ------- |
| -vv | 详细输出 |
| -z | 0数据传输 |
| grep -v refused | 过滤掉关闭端口 |
| 2>&1 | 将错误重定向到标准输出，否则grep无法过滤 |

```bash
nc.traditional -vv -z 172.16.200.131 1-65535 2>&1 | grep -v refused
```

### 伪设备实现端口扫描

该方法**只能使用Bash终端**，zsh会出错  
原理：对伪设备做**输入重定向(<)**时，Bash会主动发起一次TCP握手，如果成功了就返回退出码0，触发&&右侧的打印语句(注意Bash中，退出码为0=成功)

```bash
for i in {1..65535}; do (echo < /dev/tcp/172.16.200.131/$i) &>/dev/null && printf "\n[+] The Open Port is: %d\n" "$i"; done
```

## IPv6扫描

- 使用Nmap

```bash
sudo nmap -6 --min-rate 10000 -p- [TARGET]
```

- [IOXIDResolver](https://github.com/mubix/IOXIDResolver)
在不输入任何账号密码的情况下，远程问出一台 Windows 电脑到底有几张网卡、分别是什么 IP 地址。

```bash
sudo python3 ./IOXIDResolver.py -t [TARGET]
```

- snmpwalk
一个 SNMP 查询工具，会从目标设备上把能读到的 SNMP 信息一条条列出来，比如系统信息、网络接口、设备状态等。

| 命令/参数 | 解释 |
| --- | --- |
| -v2c | 指定使用 SNMP 版本 2c |
| -c public | 指定 SNMP 的“团体名”是 public。团体名有点像访问密码；public 是很常见的默认只读团体名 |

```bash
sudo snmpwalk -v2c -c public [TARGET]
```
