## tmux操作

tmux是一个现代化的终端复用工具，它可以把一个终端窗口切分成多个窗格，方便我们使用

启动tmux，启动之前可以先切换用户/目录，之后在tmux中每次分割的新窗格都会基于启动tmux前的用户/目录

```bash
tmux
```

要对tmux发送命令，首先要按下`Ctrl+B`

| 常用命令 | 作用 |
| ------- | ---- |
| : | 上下分割窗格，新分割出的窗格在下边 |
| % | 左右分割窗口，新分割出的窗格在右边 |
| Alt+方向键 | 更改活动窗格尺寸 |
| Z | 最大化/还原活动窗格 |
| 方向键 | 切换活动窗格 |
| ? | 显示帮助信息 |
| PageUp/Dn | 翻页 |

## Shell中快速移动光标

| 快捷键 | 作用 |
| ------ | --- |
| Ctrl+A/Home | 将光标移动到命令开头 |
| Ctrl+E/End | 将光标移动到命令结尾 |
| Ctrl+←/Alt+B | 将光标向左移动一个单词 |
| Ctrl+→/Alt+F | 将光标向右移动一个单词 |
| Ctrl+W/Alt+Back | 删除光标前的一个单词 |
| Ctrl+Delete/Alt+D | 删除光标后的一个单词 |
| Ctrl+K | 删除光标后的所有内容 |
| Ctrl+U | 删除光标前的所有内容 |
